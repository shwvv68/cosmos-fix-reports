- Plugin: cosmos-sources-tools 0.7.0

- Timestamp (UTC): 2026-08-25T135942Z
- Status: repaired

## Why the change was needed

The timeline collector treated a malformed unsupported file card on an off-target topic as a blocker after the requested date range was otherwise reachable. Expected behavior is strict attachment inventory for target-date topics while off-target topics serve only as chronology evidence.

## Reproduction

1. Open an authenticated timeline whose visible range crosses the requested date.
2. Place an unsupported non-PDF file card on a topic outside the requested date.
3. Run the range collector. Before the fix it returned `FILE_ATTACHMENT_MISMATCH`; after the fix it ignores only that off-target card and preserves strict failure for the same card on the target date.

## Changed packaged paths

- `skills/zsxq-fetch/scripts/zsxq-browser-collector.mjs`: add the v7 adapter flag and date-scoped handling for unsupported file cards.
- `skills/zsxq-fetch/tests/zsxq-browser-collector.test.mjs`: add regression coverage for off-target ignore and target-date rejection, and update active-version assertions.
- `skills/zsxq-fetch/references/runner-contract.md`: document the v7 behavior and rollback boundary.
