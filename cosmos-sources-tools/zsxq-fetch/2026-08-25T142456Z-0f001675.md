## Why the change was needed

The bundled image-tiling script imports `sharp`, but the skill runtime did not declare or install that dependency. A dense long-image extraction therefore stopped before deterministic tiling could begin.

## Reproduction

1. Run `zsxq-image-tiles.mjs` on a valid image inside a private run workspace.
2. Observe the missing-module failure for `sharp`.
3. Install the declared runtime dependency and rerun; the script emits its normalized source, deterministic tile grid, and manifest.

## Changed packaged paths

- `skills/zsxq-fetch/package.json`: declare `sharp` as a runtime dependency.
- `skills/zsxq-fetch/package-lock.json`: lock `sharp` and its platform packages.
